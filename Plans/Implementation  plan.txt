
# Step 6 - Install Playwright Browsers

Installing the package isn't enough—you also need the browser binaries:

```powershell
playwright install
```

or

```powershell
uv run playwright install
```

This downloads:

* Chromium
* Firefox
* WebKit

We'll primarily use Chromium.

# Step 11 - Initial `server.py`

Create `src/server.py`:

```python
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("Migration Validation MCP Server")


@mcp.tool()
def health_check() -> str:
    """Simple health check."""
    return "Migration Validation MCP Server is running."


def main():
    mcp.run(transport="stdio")


if __name__ == "__main__":
    main()
```

Run it:

```powershell
uv run python src/server.py
```

The process should start and wait for incoming MCP requests.
